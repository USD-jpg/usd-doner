# USD Doner — тапсырыс сайты + әкімші панелі

## Іске қосу

1. Компьютерге Node.js 18 немесе одан жаңа нұсқасын орнатыңыз.
2. Жоба бумасында терминал ашып, `npm install` орындаңыз.
3. `.env.example` файлын `.env` деп көшіріңіз.
4. Әкімші құпиясөзінің хэшін және сессия кілтін төмендегі нұсқаулықпен жасаңыз.
5. `npm start` орындаңыз.
6. Сайт: `http://localhost:3000`; әкімші: `http://localhost:3000/admin.html`.

## Әкімші құпиясөзін орнату

Құпиясөзді чатқа жібермеңіз. Терминалда өзіңіз таңдаған құпиясөзді қолданып орындаңыз:

```bash
node -e "const c=require('crypto');const p=process.argv[1];const s=c.randomBytes(16).toString('hex');console.log(s+':'+c.scryptSync(p,s,64).toString('hex'))" "ӨЗ ҚҰПИЯСӨЗІҢІЗ"
```

Шыққан `salt:hash` мәнін `.env` ішіндегі `ADMIN_PASSWORD_HASH=` жолына қойыңыз. Сессия кілті:

```bash
node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"
```

Оны `ADMIN_SESSION_SECRET=` жолына қойыңыз. `.env` файлын ешкімге жібермеңіз және GitHub-қа жүктемеңіз.

## Қосылған мүмкіндіктер

- Ақ/қызыл/қара дизайн, күндізгі және түнгі режим.
- Қазақша/орысша тіл ауыстыру (негізгі интерфейс және FAQ).
- Мәзір, іздеу, санаттар, таңдаулылар, себет және тауар нұсқалары.
- Курьермен жеткізу немесе алып кету.
- Kaspi төлем сілтемесі және Halyk алушы деректері; қолма-қол төлем жоқ.
- Тапсырыс WhatsApp-қа дайын мәтінмен ашылады; түбіртек скриншотын клиент өзі тіркеп жібереді.
- Клиент аккаунты: телефон/құпиясөзбен тіркелу және кіру; Google OAuth Client ID берілсе Google арқылы кіру. Аккаунт міндетті емес.
- Тапсырыс нөмірі мен телефон арқылы мәртебесін тексеру; соңғы тапсырыстарды есте сақтау және қайта тапсырыс беру.
- Промокодтар: әкімші пайызын, лимитін және жарамдылық мерзімін орнатады.
- Әкімші: тапсырыстар, төлем/тапсырыс мәртебелері, статистика, мәзір бағалары, промокодтар.
- PWA орнату және web push хабарландыруына жазылу негізі.

## Push хабарландыруын қосу

Сайт HTTPS арқылы жарияланғаннан кейін (localhost-та сынауға болады):

```bash
npx web-push generate-vapid-keys
```

Шыққан public/private кілттерді `.env` ішіндегі `VAPID_PUBLIC_KEY` және `VAPID_PRIVATE_KEY` мәндеріне қойыңыз. `VAPID_SUBJECT` үшін `mailto:сіздің-email` жазыңыз. Серверді қайта іске қосыңыз. Клиент сайттағы «Хабарлама» батырмасын басып рұқсат береді. Әкімші панеліндегі «Хабарландыру» бөлімінен акция хабарламасын жіберуге болады; мәртебе өзгергенде де push жіберіледі.

## Әзірге қосылмаған / дерек қажет

- Google арқылы нақты кіру үшін Google Cloud Console-да Web OAuth Client жасап, сайт доменін Authorized JavaScript origins тізіміне енгізіп, Client ID-ді `.env` ішіндегі `GOOGLE_CLIENT_ID` мәніне қою керек. Google аккаунтымен кіруде телефон нөмірі автоматты расталмайды.
- SMS растау, 500₸ бонус және дос шақыру бонусын автоматты есептеу үшін SMS провайдерінің API деректері қажет. Қазір телефон/құпиясөз тіркелуі жұмыс істейді, бірақ SMS растау мен бонус/реферал төлемі автоматты қосылмаған; сайтта расталмаған телефонға бонус берілмейтіні көрсетіледі.
- Нақты мекенжай мен карта орны пайдаланушы кейін беретін болғандықтан қазір қойылмады.
- Бірінші тапсырысқа жеңілдік әдейі кейінге қалдырылды.
- I’M KZ-ден алынған әр тағамның жеке ақ фонда фотолары әлі жүктелмеген; әзірге мәзір суреттері қолданылады.
- Төлем автоматты расталмайды: әкімші Kaspi/Halyk төлемін және WhatsApp-тағы түбіртекті қолмен тексереді.
- Сайт интернетке әлі орналастырылмаған. Онлайн іске қосу үшін хостинг және HTTPS қажет.

## Қауіпсіздік

Әкімші құпиясөзі scrypt хэшімен тексеріледі, сессия HttpOnly cookie арқылы сақталады, қате кіру әрекеттері шектеледі. Өндірісте HTTPS қолданыңыз, `.env` мәндерін хостингтің құпия айнымалыларына енгізіңіз және SQLite дерекқорының резервтік көшірмесін жасаңыз.


## Render арқылы тегін сынақ ретінде жариялау

1. Жобаның осы бумасын GitHub-та жаңа **Private repository** ретінде жүктеңіз. `.env` және дерекқор файлдарын ешқашан GitHub-қа қоспаңыз.
2. https://render.com сайтына кіріп, GitHub аккаунтын байланыстырыңыз.
3. Render ішінен **New → Blueprint** таңдап, жаңа репозиторийді таңдаңыз. `render.yaml` автоматты түрде `usd-doner` Web Service жасайды.
4. Render сұрағанда `ADMIN_PASSWORD_HASH` мәніне төмендегі нұсқаулықпен жасаған `salt:hash` мәнін енгізіңіз. `ADMIN_SESSION_SECRET` автоматты түрде жасалады.
5. Deploy аяқталған соң Render берген `https://...onrender.com` адресін ашыңыз. Әкімші панелі `/admin.html` адресінде.

### Әкімші құпиясөзінің хэшін жасау

Компьютерде Node.js орнатылған терминалда мына команданы орындаңыз (соңындағы мәтінді өз құпиясөзіңізбен ауыстырыңыз):

```bash
node -e "const c=require('crypto');const p=process.argv[1];const s=c.randomBytes(16).toString('hex');console.log(s+':'+c.scryptSync(p,s,64).toString('hex'))" "ӨЗ ҚҰПИЯСӨЗІҢІЗ"
```

Шыққан толық `salt:hash` нәтижесін Render-дегі `ADMIN_PASSWORD_HASH` мәніне қойыңыз. Құпиясөздің өзін ешкімге жібермеңіз.

### Тегін сынақ нұсқасының шектеуі

Бұл Render конфигурациясы тегін сынаққа арналған: SQLite дерекқоры `/tmp` ішінде сақталады және тегін инстанс қайта іске қосылғанда немесе ұйқыдан оянғанда деректер жоғалуы мүмкін. Сондықтан бұл режимді нақты клиенттердің тапсырысын қабылдауға қолданбаңыз. Тұрақты тапсырыс қабылдау үшін тұрақты диск (ақылы хостинг) немесе сыртқы PostgreSQL дерекқорына көшу керек. Тегін Render сервисі белсенділік болмаса ұйықтауы мүмкін.
